# کُدرا — نسخه ۴

نسخه ۴ شامل صفحه مستقل «کتاب‌ها و جزوات آموزشی» است.

## ساختار کتاب‌ها
کتاب‌ها داخل پوشه `books` قرار می‌گیرند.
اطلاعات کتاب‌ها فقط در فایل `js/books.js` نوشته می‌شود.

### اضافه کردن کتاب جدید
1. فایل PDF را داخل `books` قرار دهید.
2. در `js/books.js` یک مورد جدید به آرایه `books` اضافه کنید:

```js
{
  title: "نام کتاب",
  author: "نام نویسنده",
  subject: "موضوع کتاب",
  file: "books/filename.pdf"
}
```

نیازی به ویرایش `books.html` نیست.
